Summary

The web admin where customer accounts, retailer and salesperson lists, consents and mail settings for the configurator are managed. Customers and SparkVision staff both use it, so those changes no longer need a developer or a deploy.

What I did

  • Upgraded the admin to .NET 9 and rewrote the obsolete code.
  • Planned the Send in Shop epic across four repositories and built the salesperson protocol model, the Excel importer and the admin UI.
  • Gave each summary exit its own consent section and summary-copy switch.
  • Fixed a publish that wiped a setting on every customer, list uploads that failed when two saves overlapped, and assortments that lost their wall and floor placement.
  • Removed unused product pages and normalised the repository's line endings.
  • Added an agent guide, a glossary and a wrong-assumption log, and led an epic to keep them in every product repository.
  • Leading, alone, the migration that moves customer configuration out of the backends into the web admin: opened the epic with decision tickets on ownership, scopes, languages and a security baseline.

Outcomes

  • Holds, by my estimate, hundreds of customer accounts; one application can have several.
