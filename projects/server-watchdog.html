Summary

The watchdog that keeps the customer applications running on the production web servers: it restarts an application that fails, recycles them all nightly, and promotes a staged release to live overnight.

What I did

  • Wrote the scripts that automate the watchdog, and kept the list of watched customer applications current as they were added and retired.
  • Made the watchdog honour the new deploy service's markers and report its state, so a deploy and a restart do not collide.
  • Wrote agent notes on adding a watched application, and recorded that the Grafana dashboards count its log lines.

Outcomes

  • Supervises about 80 applications on each of the two production web servers and recycles them nightly, roughly 57,000 restarts a year.
  • Restarts an application that fails its health check three times in a row.
