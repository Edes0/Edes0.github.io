Summary

The web app where a shopper picks the room to configure before entering the configurator. It was a separate app for historical reasons until I merged it into the web front end, so there is one app to deploy.

What I did

  • Fixed lost translations and extended the configuration file names with the account id, matching the configurator's syntax.
  • Added Google Tag Manager support.
  • Made products depend on the shopper's market, added type groups for shower combinations, and removed the old memorize mode.

Outcomes

  • No longer used as its own app: it now lives inside the web front end.
