Summary

The web front end of Spark Digital Showroom: a shopper picks a room, applies tiles, floors and furniture, and leaves with a summary sent to a shop or by mail. The features that span the backend and this front end are on the Spark Digital Showroom page; this page holds the rest of the front-end work.

What I did

  • Added front-end support for new tile patterns and shapes: offset patterns, hexagons and triangles.
  • Added Google Tag Manager tracking and mail-consent checkboxes, and made consent texts follow the active account with their own section for each summary exit.
  • Maintained the model selector, where a shopper picks the room, while it was its own app: fixed lost translations, added the account id to configuration file names to match the configurator, added Google Tag Manager support, and made products depend on the shopper's market.
  • Merged the model selector into the front end.
  • Built the Bring Your Own Room screens: the add-your-room card and modal, a loading view for the shopper's room, hover states on surfaces and an apply-to-all row.
  • Introduced Playwright end-to-end tests, including cross-browser runs that caught a Firefox bug, and automated how new tests are created.
  • Pinned what one customer's room display reads from the summary page in a contract test, and made Jenkins run the unit tests.
