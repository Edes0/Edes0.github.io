Summary

A programmable idle game I am building to launch: players write a bot, by hand or with an AI assistant, in one of about 24 languages, and it plays on its own around the clock in one shared online world.

What I did

  • Built the game server in C# on .NET 10, where every bot acts once a second, with pathfinding across rooms, fog of war, economy, building and combat.
  • Built the sandbox that runs each player's bot in its own Docker container with CPU and time limits, with runtime images for about 24 languages.
  • Built the Godot client, which only draws what the authoritative server sends.
  • Run it spec-first: every change starts as a spec and plan and lands as a reviewed pull request with tests, and AI coding agents write much of the code under checks I set up while I make the design decisions and review every change.
