Summary

The Windows app that runs the configurator on a desktop or as a standalone install, and the updater that keeps it current, so in-store screens and standalone installs could run the configurator without a browser. It shipped to a few customers and is no longer in use.

What I did

  • Moved the desktop app to .NET 8 and onto a Jenkins build with publish scripts.
  • Made the standalone settings work per install type, moved credentials out of the app settings, and fixed a window that did not maximise while downloading.
  • Updated the updater: an SDK-style project, an install-later option, resumable downloads, and a shorter update check interval.

Outcomes

  • No longer in use; the v2 rewrite takes over its job.
