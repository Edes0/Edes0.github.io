Summary

A 2D Unity game with soap-bubble characters, made by a team of five at a game jam.

What I did

  • Built the soap-push mechanic with a dynamic push force and a charge-and-expand ability with a cooldown.
  • Fixed collisions and slopes and added scoring, working on one shared Git branch with the team.
