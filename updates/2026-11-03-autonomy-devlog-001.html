Autonomy devlog 001

2026-11-03

The first numbered entry, and the first time I have written this up in public. Autonomy is a programmable idle game: you write a bot and it plays on its own in one shared world.

Shipped

  • Seeded biomes, so the world has three kinds of terrain.
  • Colonies can be razed and repaired.
  • Colonies spawn from the edge of the world and spread out by a seeded pick.
  • The client loads the rooms around the camera and draws low-resolution tiles for the rest.
  • The first phase of a hosted world: a proxy, backups and a way back.

Decided

  • Workers keep world state between ticks. Resending all terrain every tick came to about 2.8 MB per player on a larger world, and in a 30-bot run no player's tick met its deadline.
  • A player's bot lives in a local folder that the client pushes, so git and the editor stay theirs.
  • The game offers only languages that run. An audit found only Python works end to end out of the 24 the server lists.

Next

  • A closed demo for 10 to 30 invited players on one hosted world.
  • More languages running end to end.
